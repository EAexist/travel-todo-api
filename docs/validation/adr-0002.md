* **Database Query Performance (pg_stat_statements)**
  - **Methodology**: Uses PostgreSQL's `pg_stat_statements` extension to track execution statistics.
  - **Pre-Test Execution**:
    ```sql
    SELECT pg_stat_statements_reset();
    ```
  - **Post-Test Analysis**:
    ```sql
    SELECT
    queryid,
    left(query, 60) AS query_snippet,
    calls,
    ROUND(total_exec_time::numeric, 2) AS total_ms,
    ROUND(mean_exec_time::numeric, 2) AS avg_ms,
    ROUND(stddev_exec_time::numeric, 2) AS stddev_ms,
    ROUND(min_exec_time::numeric, 2) AS min_ms,
    ROUND(max_exec_time::numeric, 2) AS max_ms,
    rows,
    -- Buffer Cache Hit Ratio
    ROUND(
    100.0 * shared_blks_hit / NULLIF(shared_blks_hit + shared_blks_read, 0), 2
    ) AS cache_hit_pct
    FROM pg_stat_statements
    WHERE query NOT LIKE '%pg_stat_statements%'
    ORDER BY total_exec_time DESC
    LIMIT 10;
    ```

## About The App
여권 만료일 다 돼가는 줄 모르고 있다가 여행 전날 당황할 일 없게 

손에 캐리어 두 개 가방 세개 쥐고 호텔 로비에서 식은땀 흘리며 이메일 뒤적일 일 없게 

여권, 보조배터리, 입국 서류, 짐, 미술관·테마파크·호텔·에어비앤비 예약 내역 중 꼭 한 두개씩 빼먹는 일 없게

떠나는 당신을 위한 단 하나의 투두리스트
